Library

Name of the Jellyfin library to publish VOD items into. The library must exist and have been scanned at least once.
Base URL used to build stream URLs. Must be reachable by the Jellyfin server itself (loopback is fine for single-host setups).

Playback

How long filtered HLS master playlists are cached before being re-fetched.
Maximum video height passed to HLS playlist filtering. Variants above this height are excluded. Fallback: uncapped if no variant fits.
Comma-separated BCP-47 language prefixes (e.g. en, fr). Matching audio renditions are kept in HLS masters, original track always included. Leave empty to keep the original track only.
Comma-separated BCP-47 language prefixes (e.g. en, fr). Matching subtitle tracks are included in HLS masters. Leave empty to include no subtitles.
