Libraries

Where sources set to "Movies" publish. Only libraries that can hold movies are listed — a movies library, or a mixed one.
Where sources set to "Series" publish. Pick the same library as above to keep everything together — a library that can hold both is a mixed one. Each library must exist, but needs no scan: a small .keep file is written into its folder, because Jellyfin skips a library folder that holds no files at all.
Applies to a mixed library only, so sorting by date added follows publication order. It has no effect on a movies-only or series-only library, where the view is already right. Note the trade-off: a channel you add today but which has been running for years will never appear in "Recently added", because its videos keep their old release dates. You can turn this back off at any time — nothing is overwritten. Re-typing a mixed library has the same effect as turning it off.
Base URL used to build stream URLs. Must be reachable by the Jellyfin server itself (loopback is fine for single-host setups).

Playback

How long filtered HLS master playlists are cached before being re-fetched.
How often sources are polled for a broadcast in progress. Set to 0 to disable. The sync alone cannot find a live in time: it runs per source every 720 minutes by default. The task itself wakes every 5 minutes, so any value below 5 behaves as 5.
How many videos the stream description task describes each time it runs, every 15 minutes. Set to 0 to disable the task; descriptions still happen when something is played. Each video costs one yt-dlp call and at most one probe, so a high value risks an anti-bot answer.
How long a video whose description failed is left alone before another pass tries it again.
Comma-separated BCP-47 language prefixes (e.g. en, fr). Matching audio renditions are kept in HLS masters, original track always included. Leave empty to keep the original track only.
Comma-separated BCP-47 language prefixes (e.g. en, fr). Matching subtitle tracks are included in HLS masters. Leave empty to include no subtitles.

Sources

One row per channel, playlist or single-video URL. Removing a row retires the source: its videos and its series are deleted from the library on the next sync. To stop syncing a source without deleting anything, clear its checkbox instead.
