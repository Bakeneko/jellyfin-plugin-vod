Passed to yt-dlp's --js-runtimes as NAME or NAME:PATH. Required for YouTube (deno, node, bun or quickjs). Leave empty to use yt-dlp's default.
Absolute path or PATH-resolvable name of the ffmpeg executable.
Absolute path to a Netscape-format cookie file. Use a throwaway account — this file grants full account access.

Library

Name of the Jellyfin library to publish VOD items into. The library must exist, but it does not need to have been scanned. A small .keep file is written into its folder, because Jellyfin skips a library folder that holds no files at all. Prefer a library of its own over one that already holds your media.
Base URL used to build stream URLs. Must be reachable by the Jellyfin server itself (loopback is fine for single-host setups).

Playback

How long filtered HLS master playlists are cached before being re-fetched.
Maximum video height passed to HLS playlist filtering. Variants above this height are excluded. Fallback: uncapped if no variant fits.
Comma-separated BCP-47 language prefixes (e.g. en, fr). Matching audio renditions are kept in HLS masters, original track always included. Leave empty to keep the original track only.
Comma-separated BCP-47 language prefixes (e.g. en, fr). Matching subtitle tracks are included in HLS masters. Leave empty to include no subtitles.

Sources

One row per channel, playlist or single-video URL. Removing a row retires the source: its videos and its series are deleted from the library on the next sync. To stop syncing a source without deleting anything, clear its checkbox instead.
